# Install with Codex

Copy/paste the block below into Codex (Codex CLI). It will install this repo’s `cli-wireframe` skill into your local skills folder.

```text
Use the built-in skill-installer to install a Codex skill from GitHub:

- repo: catoncat/skills-repo
- path: cli-wireframe
- dest: $CODEX_HOME/skills (default: ~/.codex/skills)

After installing, confirm the folder exists at:
  ~/.codex/skills/cli-wireframe
and tell me to restart Codex so it loads the new skill.
```
